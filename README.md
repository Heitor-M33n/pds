# 📚 Livraria Online

Aplicação web para compra e navegação de livros.

## 🚀 Funcionalidades

* Busca de livros
* Visualização de detalhes
* Carrinho de compras
* Login e cadastro

## 🛠️ Tecnologias

* Frontend: (ex: React)
* Backend: (ex: Node.js)
* Banco de Dados: (ex: MongoDB)

## ⚙️ Como rodar

```bash
git clone https://github.com/seu-usuario/livraria-online.git
cd livraria-online
npm install
npm run dev
```
